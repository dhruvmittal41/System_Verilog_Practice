# DAY 1 - Basics of System Verilog

## Need For System Verilog

#### Verilog was not good for verification engineers and they had to use other languages like 'e' for the verification tasks.
#### System Verilog solved this problem by combining the verification capabilities of HVL with verilog HDL.

## Programming Languages vs System Verilog

#### Normal Programming languages like Python,C,C++,java these are executed line by line in sequential order.
#### But Hardware design languages like verilog,SysVerilog or VHDL, executes each code block concurrently(Parallely).
#### Some concepts of OOPS are also used in System Verilog.
